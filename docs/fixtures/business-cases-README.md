# Source-derived business workflow cases

business-cases.csv is a small selection of factual fields from the locally
validated 2026-10-30 business case table, with independent Decimal expectations.
It is an offline CI sample, not the full 6347-case audit or a new dataset.
case_id, source_row, record_id and transformation preserve the original linkage.
Two complete job descriptions are deliberately not included in this small sample.

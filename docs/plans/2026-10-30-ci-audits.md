# Continuous installed-package audit coverage

**Goal:** Run existing compatibility audits automatically, without changing
package production code or adding package dependencies.

* Ubuntu R-release alone installs CI-only haven, units and bit64 dependencies.
* After the ordinary R CMD check, compile a separate installation in a temporary
  library. Execute existing system/import audits in fresh Rscript processes.
* Require all optional audit dependencies explicitly; child failures fail CI.
* Keep the five-platform package matrix and reference-manual check unchanged.
* Correct stale bilingual README scope sentences about matrices and accounting
  unit inheritance. These are documentation corrections to 0.2.24 behavior.
* Verify local scripts/README, push, and inspect final five-platform logs,
  including the additional Ubuntu audit step. No package algorithm or native
  code changes, version bump, replacement release asset, or CRAN submission.

This is repository verification/documentation maintenance on top of v0.2.25.

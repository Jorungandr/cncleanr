# 中文紧凑数值解析器设计

## 目标

`cncleanr` 第一版提供纯 R 的 `parse_cn_number()`，把中文表格中常见的紧凑数值、安全地转换为 double。它支持万、亿、万亿、百分比、全角字符、财务括号、中文缺失标记和严格模式；不处理中文文字数字、范围值、日期或自动清洗整个数据框。

## 接口与数据流

```r
parse_cn_number(
  x,
  na = c("", "NA", "N/A", "暂无", "未公布", "—", "–", "-", "...", "…"),
  strict = FALSE
)
```

输入可以是 character、factor 或 numeric。处理顺序为：保留原始值和名称；转换 factor；Unicode/全角标准化；识别缺失标记；识别财务括号和正负号；使用锚定正则完整匹配数值、单位、货币后缀和百分号；最后应用倍率。单位表固定为 `1`、`1e4`、`1e8` 和 `1e12`，避免模糊推断。

无法完整解析的非缺失值不会被静默截断。普通模式返回 `NA_real_`、发出汇总警告，并在结果的 `problems` 属性中保存位置、原值和原因；严格模式立即报错。这样既适合批量清洗，也保留审计入口。

## 测试边界

测试覆盖普通数值、逗号和空格分组、万/亿/万亿、元/人民币后缀、半角与全角百分号、全角数字、普通负数、财务括号、输入名称、numeric/factor、空向量、自定义缺失值、非法文本、范围值、近似值以及严格模式。第一版优先保证语义明确和失败可见，不加入反向格式化与 C/C++ 优化。

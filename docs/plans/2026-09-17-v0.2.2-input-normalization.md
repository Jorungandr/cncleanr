# cncleanr 0.2.2 Input Normalization Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make the existing parsers safer and more reliable for values copied from PDFs, spreadsheets, and web pages.

**Architecture:** Separate character normalization from whitespace removal so digit grouping can be validated before spaces disappear. Continue routing semantic qualifiers through `parse_cn_quantity()` and extend its existing `余` handling to values where `余` appears before a magnitude or currency suffix.

**Tech Stack:** Base R, roxygen2, testthat 3, GitHub Actions.

---

### Task 1: Add failing normalization tests

**Files:**
- Modify: `tests/testthat/test-parse-cn-number.R`
- Modify: `tests/parser.R`

**Steps:**
1. Test Unicode minus, small minus, en dash, and full-width scientific notation.
2. Test regular, non-breaking, narrow no-break, and ideographic grouping spaces.
3. Require valid three-digit grouping to parse.
4. Require malformed grouping such as `1 2` and `12 34` to fail with a specific reason.
5. Run tests and confirm the new cases fail before implementation.

### Task 2: Refine normalization and whitespace validation

**Files:**
- Modify: `R/parse-cn-number.R`

**Steps:**
1. Extract character-only normalization into an internal helper.
2. Normalize PDF minus variants and full-width exponent letters.
3. Explicitly recognize Unicode spacing characters.
4. Detect whitespace between digits before removing it.
5. Allow only one-to-three leading digits followed by groups of exactly three digits.
6. Attach the reason `digits use invalid whitespace grouping` to rejected values.

### Task 3: Complete `余` placement handling

**Files:**
- Modify: `R/parse-cn-quantity.R`

- Modify: `tests/parser.R`

**Steps:**
1. Test `50余`, `10万余`, `50余万`, `50余元`, and `50余万元`.
2. Recognize `余` before a magnitude or currency suffix and reconstruct the exact numeric expression.
3. Preserve the `greater_than` qualifier for all supported placements.
4. Verify range bounds remain open at the lower boundary.

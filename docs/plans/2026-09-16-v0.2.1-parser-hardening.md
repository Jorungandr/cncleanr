# cncleanr 0.2.1 Parser Hardening Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Improve the correctness and diagnostics of the existing number, quantity, and range parsers without adding a new public API.

**Architecture:** Keep `parse_cn_number()` as the exact-value parser and `parse_cn_quantity()` as the sole interpreter of inequality semantics. Make `parse_cn_range()` try a complete quantity first, then identify a range separator only when two valid endpoints exist, preventing exponent signs from being misread as separators.

**Tech Stack:** Base R, roxygen2, testthat 3, GitHub Actions.

---

### Task 1: Lock down inequality semantics with tests

**Files:**
- Modify: `tests/testthat/test-parse-cn-quantity.R`
- Modify: `tests/parser.R`

**Steps:**
1. Add failing cases for `大于3万`, `小于3万`, `不大于3万`, and `不小于3万`.
2. Add cases for `<`, `>`, `<=`, `>=`, `≤`, and `≥`.
3. Specify `10万+` as `at_least` and `50余` as `greater_than`.
4. Run the focused tests and confirm unsupported forms fail before implementation.

### Task 2: Complete quantity recognition

**Files:**
- Modify: `R/parse-cn-number.R`
- Modify: `R/parse-cn-quantity.R`

**Steps:**
1. Normalize full-width comparison characters.
2. Add ordered prefix rules for inclusive and strict inequalities.
3. Add suffix rules for `+` and `余`.
4. Run quantity tests and verify qualifier values exactly match the agreed semantics.

### Task 3: Harden range separator detection

**Files:**
- Modify: `R/parse-cn-range.R`
- Modify: `tests/testthat/test-parse-cn-range.R`
- Modify: `tests/parser.R`

**Steps:**
1. Add failing tests for exact `1e-3`, range `1e-3-2e-3`, and negative range `-5--3`.
2. Parse a complete exact or qualified value before considering range separators.
3. Evaluate every potential separator and accept only the split that yields two valid endpoints.
4. Reject zero valid splits as invalid and multiple valid splits as ambiguous.
5. Run range tests and confirm shared-unit propagation still works.

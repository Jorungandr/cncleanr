# CRAN 0.2.7 更新准备

2026-10-09 核对[CRAN 元数据](https://cran.r-project.org/web/packages/cncleanr/DESCRIPTION)：
当前版本 0.2.5，发布日期 2026-09-30，距核对日期 9 天。
[CRAN 政策](https://cran.r-project.org/web/packages/policies.html)建议已稳定包一般
每 1–2 个月更新。此轮没有紧急错误修复，先准备，不立即上传；提交前重新核对版本和政策。

## 更新范围

- 0.2.6：可选金额表头单位、千元、简写限定词“超”，缺少数值的限定词安全拒绝。
- 0.2.7：一个近似前缀和一个近似后缀可同时存在；重复限定词及混合不等式仍拒绝。
- 新增清洗示例、回归测试和本地多领域审计；没有新依赖或原始数据入包。
- `unit` 位于已有参数之后，不改变既有位置参数调用；未声称支持任意物理单位。

## 已完成与待完成

正式上传前还需：

1. 重新构建最终源码包，记录校验和并运行提交检查。

3. 核对 CRAN 检查页、反向依赖、上传频率及是否已有待处理提交。
4. 将草稿中的待办改成实际证据，再经维护者确认后上传并完成邮件确认。

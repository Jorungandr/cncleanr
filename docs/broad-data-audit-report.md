## 实际发现与限制

- 旅游字段不仅有数字，还有 `#VALUE!`、`未統計`、活动停办说明，以及
  `27,091(外國跑者3,249人)` 等多个数字混在一起的文本。48 项全部拒绝；
  需要人工选择含义，不能直接将它们都置为缺失，或者从长文本提取第一个数字。
- 旅游经济效益列的标题单位是“萬元”，脚本仅对这一个金额列显式指定 `unit='万元'`，
  预期数值独立乘以 10000。人数列不进行金额换算。
- 就业统计原始单位为“千人”及“百分比”：检查保留源数字与单位，不自动转换。
  百分比列的裸数字 11.81 仍是 11.81，不能默认为 0.1181。
- 空气测量的 ppb、ppm、μg/m³、风速等也保留源单位，未声称包能够完成物理单位换算。
- 招聘快照 1000 条，包含月薪 753、时薪 158、按学历证照核薪 77、论件计酬 5、
  部分工时月薪 5、日薪 2。薪资下限、上限是独立字段，不能直接跨核薪方式比较。
  692 个 `lower~upper` 区间由两个有效端点构造，不是源数据原本存在的中文薪资表达。
- 世界银行 9275 条记录是 7 指标 × 265 个国家/地区或汇总区域 × 5 年，
  不是 265 个独立国家，也不是 9275 个互不相关的数据集。共有 301 个负数数值。
  入学率是毛入学率，可能超过 100；没有添加错误的 0–100 约束。
- 世界银行等原本就提供普通数字。这些检查验证数值保真、缺失、分组符和列单位，
  不能据此宣称中文“万/亿”、限定词、范围等全部经过新的真实语料覆盖。
- 空气质量是单次小时快照；就业是下载接口当时返回的 1000 条，不保证是全部职位。

## 来源、授权和快照

世界银行 WDI 的 API 请求如下，时间范围 2020–2024，元数据 `lastupdated=2026-07-13`：

```text
https://api.worldbank.org/v2/country/all/indicator/SP.POP.TOTL;NY.GDP.MKTP.KD.ZG;SE.SEC.ENRR;EG.FEC.RNEW.ZS;AG.LND.FRST.ZS;SP.DYN.LE00.IN;SL.UEM.TOTL.ZS?source=2&date=2020:2024&format=json&per_page=20000
```

世界银行数据默认适用 CC BY 4.0，但存在指标/第三方例外及额外条款；
本轮只本地测试，不再分发数据。参见[官方使用条款](https://data.worldbank.org/summary-terms-of-use)
与[API 文档](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392)。

台湾四份资料的官方元数据 `license=1`，公开页面标明政府資料開放授權條款第1版：

- [就业者之教育程度与年龄，34112](https://data.gov.tw/dataset/34112)：选择 114 年 XML，25 个地区记录。
- [职缺资料，44062](https://data.gov.tw/dataset/44062)：JSON 下载资源 `A17000000J-030144-nkP`，1000 条。
- [空气品质指标 AQI，40448](https://data.gov.tw/dataset/40448)：官方发布的 JSON 资源，84 个测站记录、16 个测量字段。
- [台湾观光双年历人数与经济效益，42792](https://data.gov.tw/dataset/42792)：CSV，800 个活动、2 个目标字段。

元数据入口为 `https://data.gov.tw/api/v2/rest/dataset/{id}`。
按元数据中的 `resourceDownloadUrl` 下载对应资源；空气接口使用的是元数据公开提供的 API 参数，
不是维护者的私有密钥。来源会更新，重复下载可能得到不同快照；以 SHA-256 区分。

## 复跑

先按以上来源取得同名文件，放入 `outputs/broad-data-audit/`，安装 cncleanr 0.2.7 后执行：

```powershell
python docs/broad-data-audit.py
Rscript docs/broad-data-audit.R outputs/release-0.2.7/library
Rscript docs/multi-source-audit.R outputs/release-0.2.7/library
```

第一个脚本只依赖 Python 标准库，以 Decimal 生成预期值；第二个脚本以相对容差 1e-12
比较 R 的双精度结果，写出 `results-0.2.7.tsv`，出现错误或长文本误接受便失败。
第三个命令需要既有审计的原始快照，复跑金融、科学与生物学数据。

## 方法和 0.2.5 基线结果

从答案中按固定规则提取带百分号、金额或万/亿单位的完整数字片段，
保留相邻限定词，保留错误逗号分组，避免只截取错误数字的有效后半段。
这是数值片段的词法验收，抽取器不是包功能，也不是全面文本理解评测。
预期值来自原文数值的单位换算，不代表验证了财报事实。

| 检查 | 数量 | 结果 |
| --- | ---: | --- |
| 全部带单位片段 | 1,418 | 1,403 正确；15 拒绝；0 错误接受 |
| 格式有效片段 | 1,412 | 1,403 正确，99.36%；9 拒绝 |
| 格式错误片段 | 6 | 全部安全拒绝 |
| 去重后的片段 | 1,125 | 1,111 正确；14 拒绝 |
| 适合转换为区间的有效片段 | 1,393 | 1,384 正确；9 拒绝；0 错误接受 |
| 手工核对的原始片段 | 12 | 数值与限定词全部正确 |
| 整条财报答案 | 2,100 | 全部拒绝，不会偷偷返回其中第一个数字 |

数值比较容差为 `max(1, abs(expected)) * 1e-12`，限定词与开闭边界
要求完全相同。19 个 approx 片段不要求产生确定区间。
范围测试由数值/限定词推导边界，未包含真实双端薪资区间。
这批数据也没有覆盖所有金融负数、PDF 空白、全角数字和科学计数法。
零错误接受仅适用于当前抽取规则和样本，不能视作对所有输入的保证。

`368,75万元`、`人民币10,0000000元`、`人民币 44,482,684,72元`
被拒绝是正确行为，不应自动删除逗号来提高成功率。

## 使用结论

已经分列或明确抽取出的财报金额、百分比和万/亿数量很好用；
同一批样本的数值换算与限定词保留表现稳定，失败可由 cn_problems 定位。
整段答案需要上游提取目标字段，表头单位如“单位：千元”需要另行处理。
“减少 7.48%”的下降方向、人数/面积的物理单位、百分点与百分比的
区别，以及原数据是否有事实错误，都不能仅靠这个包判断。

## 0.2.6 开发版修复后复测

补充 `千元` 和简称“超”后，同一批 1,418 个片段中，1,412 个合法
片段全部匹配预期，6 个错误格式全部拒绝，没有错误接受。
1,393 个具有确定边界的片段全部匹配预期，12 个人工核对案例通过。
这些结果不代表任意中文文本都能解析，也不替代上面的测试限制。

回归测试同时覆盖共享后缀、负数区间、冲突限定词、溢出，以及
只有限定词或限定词后接缺失标记的无效输入。暂不需要 C 实现。

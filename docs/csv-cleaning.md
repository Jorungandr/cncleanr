# CSV 导入、清洗与异常导出

[English](csv-cleaning_EN.md)

分批、连续筛选与重复取行见[进阶流程](cleaning-workflows.md)，包含共享可运行示例与回归检查。

运行[完整示例](csv-cleaning.R)：

```powershell
Rscript docs/csv-cleaning.R
```

所有输入都是人为构造的演示数据，不计入真实数据测试量。
脚本在本次 R 会话的独立临时目录生成 `input.csv`、`cleaned.csv` 和 `problems.csv`。
临时目录可能在会话结束时被清理；用于查看长期结果时，请将示例改为明确的新输出路径，
确认文件不存在后再写入，不要直接覆盖已有文件。

## 关键处理

- `read.csv(..., colClasses='character', na.strings=character())` 保留原文，
  编号 `0001` 不会变成 `1`，源文本 `暂无` 不会在导入时丢失。
- 金额列的源单位明确为万元，仅该列传入 `unit='万元'`，输出单位为元。
- 人数列只解析数值，原文 `0007` 保留，同时得到数值 7。
- 比率列明确定义为“百分数值”：裸数字 `11.81` 先加 `%`，已带 `%` 的 `5%` 不再加，
  输出比例 0.1181 与 0.05。不能将此处理套到定义不清的列。
- 用 `cn_problems()` 定位异常，保存原始行位置、编号、字段、原文与原因。
  行位置是数据行位置，不是包含表头或多行字段的 CSV 物理行号。

结果里 `1 2` 和 `bad` 是异常；`暂无` 和 `-` 按默认标记作为缺失，
因此不会进入异常清单。同一源数据行的不同列可产生两条异常，不能按行去重。
警告仅在随后检查完整异常表时抑制。

导出后脚本重新读入并验证原文、前导零、比例值和异常原文。
输出数值缺失写成空单元格，原文列仍保留源标记。
CSV 本身不保存列类型；Excel 自动打开仍可能显示编号为数字，必要时通过文本导入指定编号列类型。
本例只处理 UTF-8 CSV，不自动检测 GBK、Excel 文件或业务字段含义。

## CSV 不是无损的 R 对象备份

这里的往返检查只验证示例数据，不保证任意 double 值逐位不变。
普通 `write.csv()` 可能舍入末尾有效位（例如 `1 + 2^-52` 可写成 `1`），
负零的符号也可能丢失。`na=''` 会把 `NA`、`NaN` 都写成空单元格，无法仅凭该列恢复
二者区别；原文为空字符串时还需要单独的缺失状态列。`Inf`／`-Inf` 的文本不是
缺失值，也不能据此把区间的开放边界与数值型无穷点输入混为一谈。

交换 CSV 时保留原文、ID、状态、限定词／边界包含标志和独立的问题表，不要只留数值列。
若要在 R 中无损保存当前解析对象（包括诊断属性、NaN 和负零），使用：

```r
saveRDS(parsed, "parsed.rds")  # 先确认目标路径不会覆盖需要保留的文件
restored <- readRDS("parsed.rds")
stopifnot(identical(restored, parsed))
```

这里只读取自己保存或可信来源的 RDS 文件；RDS 不是跨软件通用的 CSV 替代格式。
